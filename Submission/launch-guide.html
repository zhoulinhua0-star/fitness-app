00

购买 Apple Developer 账号

$99/年耗时 几分钟 – 48 小时你来做
  1. 准备前提

    一个开启了双重认证(2FA)的 Apple ID、一台 Mac、一张可付款的信用卡。

  2. 选择账号类型:个人(Individual)

    去 developer.apple.com/programs/enroll → Enroll。

    选 Individual / Sole Proprietor——最快,不需要 D-U-N-S 邓白氏编码。Organization(公司)类型免费但要 D-U-N-S,审核要几天,个人开发者不必走。

  3. 付款并等待激活

    支付 $99 年费,通常几分钟内激活,最长约 48 小时。收到激活邮件即可。

一个账号,全球发行你不需要为美区和中国区分别开账号。一个开发者账号可以把 App 发行到所有 App Store 国家/地区,包括美国和中国大陆。账号注册地 ≠ 能卖的区域。
01

在 App Store Connect 建 App 记录

耗时 ~30 分钟你来做
  1. 签署协议

    登录 appstoreconnect.apple.com → Business(协议、税务、银行)→ 签署 Free Applications 免费应用协议。RepDay 免费,不需要填银行/税务(那是收费或内购才要)。

  2. 注册 App ID

    Xcode 会在自动签名时帮你注册,或手动去 Certificates, IDs & Profiles 注册 Bundle ID:

    com.zhoulinhua0-star.FitnessApp2026New
  3. 创建 App

    Apps → + → New App。填:

    平台 iOS · 名称 RepDay · 主语言 English (U.S.) · Bundle ID 选上面那个 · SKU 随便一个唯一串(如 repday-001)。

    名称可用性"RepDay" 在 App Store 必须全球唯一。若被占用,ASC 会提示;可加副标题或微调。中文本地化名之后可另填(如 RepDay 健身课表)。
02

开启 CloudKit(为"一起锻炼"计数器)

耗时 ~10 分钟你来做→ 之后代码我写
  1. 加 iCloud + CloudKit capability

    Xcode → 选 FitnessApp target → Signing & Capabilities → 左上 + Capability → 双击 iCloud → 勾选 CloudKit。

    这一步需要付费账号已激活(阶段 00),它会自动更新 FitnessApp.entitlements(现在是空的)和描述文件。

  2. 创建 Container

    在 CloudKit 面板点 + 新建容器,用默认名即可:

    iCloud.com.zhoulinhua0-star.FitnessApp2026New
  3. 确认容器已就绪

    去 icloud.developer.apple.com(CloudKit Console),能看到这个容器和它的 Public Database 就对了。记录类型(record type)之后由代码创建,不用手动建。

最简单方案的一个诚实前提公共数据库读取无需登录 iCloud;但写入(给计数 +1)需要用户设备已登录 iCloud。没登录的用户仍能看到人数,只是不计入自己那一票。对"励志展示型"数字完全够用。另外 CloudKit 无服务端原子自增,高并发下数字可能略微偏小——精确计数才需要真正的服务器(那会牵回备案)。

05

截图 & 商品页

耗时 ~1–2 小时你来做
  1. 截图(现在只需 iPhone)

    需要两个尺寸各一组:6.9" 和 6.5"。在模拟器上跑对应机型,按 ⌘S 保存:

    6.9" → iPhone 16 Pro Max(1290×2796)· 6.5" → iPhone 11 Pro Max(1242×2688)。每组建议 4–6 张:课表、今日训练、即兴模式、训练日历、模板库。

  2. App 图标

    1024×1024 PNG,不能有 alpha 透明通道和圆角(系统自动加圆角)。

  3. 文案与分类

    名称、副标题(Subtitle)、关键词(Keywords)、描述(Description)、分类 Health & Fitness、年龄分级问卷(健身内容一般 4+)、Support URL。需要我帮你写英文商品页文案,随时说。

06

打包、上传、提交审核

耗时 ~30 分钟 + 审核 24–48h你来做
  1. 每次上传前给 build 号 +1

    MARKETING_VERSION = 1.0 保持;CURRENT_PROJECT_VERSION(build 号)每次上传都要递增。

  2. Archive

    Xcode 顶部机型选 Any iOS Device (arm64) → 菜单 Product → Archive。

  3. 上传到 App Store Connect

    Organizer 窗口 → 选中 archive → Distribute App → App Store Connect → Upload。或用 Transporter App 上传导出的 .ipa。

  4. 在 ASC 选 build 并提交

    回到 App 版本页,选中刚上传的 build,补齐商品页/隐私/审核备注 → Add for Review → Submit。审核备注里写清:纯本地健身工具、无账号、日历为可选授权。

07

中国区:ICP / App 备案(并行,不阻塞美区)

耗时 ~1–3 周你来做
  1. 认清门槛

    中国大陆上架现在基本都要 ICP / App 备案,和有没有后端无关。通常需要国内主体 + 国内云服务器/域名,个人备案对 App 类目限制多。

  2. 找一家备案服务商确认口径

    规则一直在变。阿里云/腾讯云都有备案代办,先咨询个人 vs 企业备案对健身工具类的当前要求。备案是流程时间,让它在后台跑。

  3. 计数器的中国区落地

    CloudKit 在中国区可用性需实测;若备案要求国内服务器,中国区那版计数器可能改用国内云(腾讯云开发 / LeanCloud),或中国区 v1 先不上计数。

推荐节奏美区先上(阶段 00–06),中国区备案(阶段 07)并行推进——别让备案卡住整体上线。
